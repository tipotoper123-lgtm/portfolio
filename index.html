A clear path from task to tool

Agree on the input, the expected output and a small, testable scope.

  1. Understand the task

    Review the workflow, example files, integrations and any access constraints.

  2. Define the deliverable

    Agree on features, output formats and acceptance checks before implementation.

  3. Build & review

    Show a working version on test data and check normal and error cases together.

  4. Hand over

    Provide the agreed code, setup instructions and a walkthrough of the result.
